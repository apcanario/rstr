## Should-fix

**S1. `tools/smoke.py:188`: "smoke: passed" hides the skipped online lines.**
Fix: have `fontcheck.run` return the number of skipped checks. Then print `smoke: passed, 3 online checks SKIPPED (not verified)`, so the summary itself carries the gap. Keep exit 0, since the workspace cannot reach Google. The changelog's Checks column must say the three lines are unverified. Carry "run smoke and `tools/fetch_fonts.py --check` where Google Fonts is reachable" to Carried under R3 until it is done.

**S2. `tools/sheet.py:73-78`: the pairing sheets do not say when a pairing is missing.**
The Done-when sheet line is false offline, and only the image labels show it.
Fix: count the cells drawn as the default and print `pairings-<style>.jpg: N of M pairings NOT LOADED (drawn as the default)`. Also carry this item until the sheets are rebuilt online and Pedro sees all 42.

**S3. `src/engine/layout.ts:101` and `src/api.ts:70`: the Scene records families, not faces, and `unloaded()` tests measured families against `loadedFamilies()`.**
`loadedFamilies()` counts a family as loaded if any one of its faces is loaded. Canvas silently substitutes a near weight or a synthetic italic for a face that is not loaded, and the check would pass. A Scene measured with Inter Tight 300 while only 400 to 800 are loaded is one example.
Fix: record `faceKey(f)` in `measured` and in `Scene.fonts` (or add `Scene.faces`). Check every measured face with `isLoaded` in `api.fonts.unloaded`. Add a unit case in which a pairing names a weight the registry lacks.

**S4. `src/app/app.css:23`: the font note is cut off at 360 x 640.**
`screen-360x640-pomo.png` shows "Eczar / Gentium fonts not available, shown in Bricolag…". The note loses its point, which is to say what is shown instead. It gets worse when the core-failure note is added on with " · ".
Fix: shorten the text in `src/app/App.tsx` (`fontsFor`) to `<pairing name> offline · <default name>`. Allow a second line (`white-space: normal`, two-line clamp), or shrink the text to fit as spec 10.1 asks for text on controls. Make sure `.stage.noted` padding matches the note's height.

**S5. `src/data/pairings.json` (`br-big-shoulders`): `Big Shoulders Display` may no longer be a Google Fonts family name.**
I cannot verify this either way here. If the name has gone, css2 answers 400, the pairing never loads, and the note shows every time the type seed lands on it.
Fix: online, run `python3 tools/fetch_fonts.py --check` before closing. If the name fails, swap the pairing to the family that replaced it (`Big Shoulders`, with an optical-size value if needed), as a `sources` alias like `Archivo Expanded`, and record the swap in the changelog. Do the same for any other family `--check` reports. The row asks for this check, and it has not been done.

## Minor

**M1. `public/sw.js:26-28`: the `rstr-app-v1` cache grows forever.**
Every deploy adds new hashed `assets/*.js` and `*.css`, and every `?s=` navigation URL is stored under its own key.
Fix: store navigations under the bare `index.html` (strip the search), and on `activate` delete the hashed assets that are not in the current page. Or bump the cache name per build and drop old caches on `activate`.

**M2. `src/app/App.tsx:115`: switching style ignores the offline preference.**
Switching style clears `pick.pairing` and keeps the type seed, so offline it often lands on a pairing that is not loaded. `screen-*-pomo.png` shows the note on a plain style tap.
Fix: apply the same offline preference as Shuffle (line 85): offline, keep a type seed that resolves to an available pairing or choose one that does. Factor the loop into one helper. Neither path is tested; add an app check in `fontcheck.py` with the font hosts aborted and `navigator.onLine` false (`ctx.set_offline(True)`).

**M3. `src/fontcss.ts:199` (and `tools/fetch_fonts.py:121`): fallback to every subset slice.**
When a face has neither latin nor latin-ext, `rulesFor` falls back to every rule, and `addFace` fetches every file eagerly. For a CJK family split into numbered slices, that could be about 100 downloads. DotGothic16 and Dela Gothic One are the families at risk if their responses lack a latin block. I cannot verify that offline.
Fix: if the response has no latin or latin-ext block, keep only the slices whose `unicode-range` covers U+0041-005A. Or treat the face as failed.

**M4. `tools/fetch_fonts.py:97`: the default `--out` is `public/fonts/gf`, and it is not in `.gitignore`.**
A local run without `--out` puts every font into the web build, and the files can be committed by accident.
Fix: add `public/fonts/gf/` to `.gitignore`, or default `--out` to `dist-apk/fonts/gf` and let the APK build copy it.

**M5. `tools/smoke.py:91`: nothing asserts `typeMoved`.**
Offline it was 0 for three styles, so the browser 9.3 type check proves nothing there.
Fix: when `online()` is true, fail if `typeMoved == 0` for any style. Otherwise print that the real-font type check is covered by the stub-measure unit test only.

**M6. `tests/proof.test.ts:16`: the vapor guard was loosened from 10 to 12.**
The new limit rests on stub widths from a name hash, not real metrics, so the number says little about real faces.
Fix: keep 12, but say in the comment that the figure is stub-only. Re-derive it from the online run when that is possible.

**M7. `tools/fetch_fonts.py:128-133` and `:147-151`.**
`--check` downloads every font file. The licence of each core family is written twice, once from `public/LICENSES.txt` and once from google/fonts.
Fix: in `--check`, issue only HEAD requests for the files, or skip them. Skip families that are already in the core set when collecting licences.

**M8. `src/fonts.ts:75-81`: `swReady` can wait up to 1.5 s before the first font fetch on a first visit.**
That wait counts against the 4 s budget, so a slow first fetch falls back more often.
Fix: start the 4 s timer after `swReady`, or cut the grace period to about 500 ms.

**M9. Data choices to record under Choices in the changelog when the row closes.**
- Serif-contrast Swiss pairings use the serif italic for the subtitle only, and Inter 500 (or the grotesque's 500) for the text.
- `sw-inter-tight` keeps a label at 700.
- Postmodern `text` = the mono.
- Vaporwave pairings add DM Mono for the caption.
- `Archivo Expanded` is an alias for Archivo at wdth 125.
- The brutal band is measured with core faces only.
